# 연구 지도를 읽고 갱신하는 방법

## 연구의 단위

감정 인식, 상황 추론, 공감 표현, 정서 지원 효과, 주관적 경험을 구분한다. 모델이 어떤 경험을 갖는다는 결론은 언어의 인간 유사성이나 이 지도에 수집된 벤치마크 점수만으로 뒷받침되지 않는다. 행동적 성능과 실제 인간 효과가 연구의 기본 측정 단위다.

현재 자료는 목적에 맞춰 선별한 scoping map이다. 체계적 검색·전수 선별·원문 전체 독해가 완료된 systematic review가 아니다. 논문에서 보고한 주장은 출처 초록을 그대로 제시한다. 소분류의 가설과 공백은 검토자의 제안으로, 저자가 지적한 한계 또는 아직 아무도 다루지 않은 영역이라고 확정하지 않는다. 각 실험의 수치·통계·dataset 구성·baseline 공정성은 원문 검토가 남아 있다.

## Pivot 선정과 순위

각 소분류에서 foundation, development, benchmark, counterpoint, recent 역할을 보완적으로 선정한다. `pivot_basis=editorial_candidate`는 읽기 후보이며 영향력 순위가 아니다. 인용이 많다는 주장은 조회한 수치와 날짜가 있을 때만 한다.

인용 데이터가 확보되면 **해당 후보군 내** 전체 인용 수 순위를 제공한다. 인용 수에는 연령·분야·버전 병합·데이터베이스 편향이 있다. 같은 연도군의 인용 속도, 벤치마크 확산, 반증 연구, 최근 연구의 대표성을 병렬로 검토한다. 숫자를 임의로 합산해 객관적인 영향력 점수처럼 제시하지 않는다. 연도별 정규화나 PageRank를 아직 계산하지 않았다.

학회별 전수 검색 및 최신 주제의 빈도·증가율 분석이 없으므로 “2026년 가장 뜨거운 주제”를 확정하지 않는다. 최근 ACL·EMNLP 자료에서 appraisal 기반 원인 추론, 기억에 의한 정서 추론 변화, 아첨의 인간 판단 효과, 개인화된 상태 표현 등의 검토 후보를 발견한 범위다. ICML·NeurIPS·ICLR·AAAI·CHI를 포함하는 균형 잡힌 조사가 필요하다.

## 근거와 상태

- `publisher_verified`: 출판사의 공식 GitHub 메타데이터에서 제목·연도·학회·초록을 확인했다. 논문의 결론이 재현되었다는 의미는 아니다.
- `author_repository`: 저자 저장소의 서지 정보. 출판사 대조가 남을 수 있다. 학회 정보를 확인하지 못하면 null로 둔다.
- `index_unverified`: OpenAlex의 색인 정보. 학회 게재와 주제 관련성을 별도로 검토해야 한다.
- `abstract_only`: 초록을 검토한 수준. 전문 독해·결과 재현이 아니다.
- `metadata_only` / `unreviewed`: 결과·한계에 대한 판단을 아직 하지 않는다.
- `citations=null`: 미조회다. 인용 0회로 해석하지 않는다. 수치에는 출처와 조회일이 필수다.

공식 ACL Anthology XML에서 선택한 레코드의 초록을 catalog에 보존하고, 원본 URL·조회일·원본 전체 파일의 SHA-256을 함께 기록했다. 해시는 해당 조회의 사본을 식별하며 변경 가능한 master URL의 영구 고정을 대신하지 않는다. 일부 저자·출판사 자료는 sources 디렉터리에 별도 보존한다.

## 관계의 의미

| 관계 | 필요한 근거 | 해석 |
|---|---|---|
| 주제 포함 | 편집상 분류 | 탐색 구조. 논문 간 인용 아님 |
| `cites` | 출처의 referenced_works 또는 참고문헌 | A → B는 A가 B를 인용함. 지지·확장 의미 아님 |
| `extends` | 본문 절·페이지·인용 문구와 검토자 | 내용상 확장으로 읽은 이유를 보존 |
| `challenges` | 본문 절·페이지·인용 문구와 검토자 | 어떤 주장/조건을 반박하는지 명시 |
| `reading_path` | 편집상 이유와 출처 | 권장 읽기 순서. 계보 아님 |

초기 후보 간 직접 인용선은 미수집 상태다. 없는 선은 관계가 없다는 증거가 아니다. 그래프에는 여러 부모와 순환이 가능하므로 데이터는 트리가 아닌 그래프다. 트리 화면은 주제 분류를 읽기 쉽게 제공한다.

## 인용 확장의 경계

`enrich_citations.py`는 DOI 또는 제목의 정규화된 정확 일치와 연도를 확인한다. 모호한 결과는 자동 선택하지 않고 실패한다. 제목의 비슷함만으로 연결하지 않는다. 피인용 후보는 `referenced_works`를 다시 확인한다. 검토한 원본 응답은 citation-snapshots에 저장한다. API 키는 출력·사본에 저장하지 않는다.

전방 확장은 출발 논문별 최대 N편으로 제한하며 전역 인용 수 내림차순으로 표집한다. 따라서 전수 계보가 아니고, 새로운 반론이나 인용이 적은 연구가 누락될 수 있다. 참조 목록에 있는 다른 읽기 후보 간 인용도 보존한다. 이웃에게 상속한 주제는 임시 분류이며 내용 관련성 판단이 아니다. 출처 오류 또는 모호한 매칭이 있으면 catalog를 부분 덮어쓰지 않는다.

## 연구 질문을 좁히는 실험 초안

“Appraisal 상태가 장기 정서 지원의 적응을 개선하는가?”를 시험하려면 동일 base model에 (1) 원 대화 이력, (2) 일반 요약 메모리, (3) 동일 크기의 학습 latent state, (4) 명시적 appraisal 상태를 비교한다. 토큰·학습량·모델 크기를 맞추고 상태 제거·치환 개입을 수행한다. 사용자 선호 변화, 오해 정정, 문화·언어 전이 조건을 분리하고 감정 예측 정확도·지원 전략 적절성·동조·사용자 자율성을 따로 측정한다. 이는 검증할 설계 제안이며 미탐구 영역의 확정 선언이 아니다.

## 남은 조사

1. 공식 학회 및 원문 접근을 복구해 전 학회의 검색식·기간·포함/제외 기준을 고정한다.
2. 소분류별 인용 수와 피인용 이웃을 수집하고 DOI·preprint/게재본을 병합한다.
3. 논문 전문에서 핵심 주장·방법·표본·정량 결과·저자가 선언한 한계를 페이지별로 기록한다.
4. 직접 인용 가운데 실질적 확장·반론을 구분해 reviewer와 근거를 추가한다.
5. 소분류별 상대적으로 오래된 pivot과 최근·반증 연구를 보완하고 최신성·분야 균형을 재평가한다.
